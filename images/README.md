# AQUA-SWEEP Project Images

This directory contains photographs documenting the development of the AQUA-SWEEP prototype.

The images cover:

- Initial material preparation
- PVC hull fabrication
- Catamaran hull development
- Buoyancy testing
- Propulsion system
- Electronics and wiring
- ESP32 development
- Waste-collection mechanism
- Prototype assembly
- Painting and finishing
- Experimental modifications
- Final prototype
- Conceptual future swarm deployment
